Cómo sacar la llave (una sola vez, ~15 minutos)

  1. Entra a console.cloud.google.com con la cuenta de la universidad y crea un proyecto (o usa el de los Forms).
  2. Facturación: Google exige ligar una cuenta de facturación (tarjeta) aunque no cobre. Tiene usos gratis cada mes por servicio; lo que hace Admisiones queda muy por debajo. Pon una alerta de presupuesto (Facturación → Presupuestos y alertas), p. ej. de $100 MXN.
  3. APIs y servicios → Biblioteca, habilita: Maps JavaScript API, Places API (New) y Geocoding API.
  4. APIs y servicios → Credenciales → Crear credenciales → Clave de API.
  5. En la clave, restríngela (si no, cualquiera que la vea puede gastar a tu nombre):
    • Restricciones de aplicación → Sitios web → agrega {{ origen }}/* y http://localhost:8000/*.
    • Restricciones de API → solo las tres de arriba.
  6. Copia la clave (empieza con AIza), pégala aquí y guarda.

Si el mapa de prueba dice que Google rechazó la llave: revisa que la facturación esté activa, que estén habilitadas las tres APIs y que la restricción de sitios web tenga exactamente {{ origen }}/*. Los cambios en la consola de Google tardan unos minutos.

Qué se envía a Google: las coordenadas del mapa que estás viendo y lo que escribes en el buscador de «Ubicar». Nunca datos de aspirantes.
