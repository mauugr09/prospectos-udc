Conectar otra computadora

Windows (lo más fácil)

  1. counter_1
    Copia el programa a la otra computadora El mismo zip, descomprimido en C:\Prospectos. Sin la carpeta datos de esta computadora.
  2. counter_2
    Ábrelo y elige «C · Conectarme a la principal» En la misma red la encuentra sola: pulsa Enter. Desde otro plantel o la VPN, escribe la dirección fija.
  3. counter_3
    Compara el código y acepta el certificado Si coincide con el de esta pantalla, escribe S. Windows pregunta si instalas el certificado: «Sí». Desde entonces, doble clic en Prospectos.exe abre directo.

Mac, o sin copiar el programa

  1. counter_1
    En el navegador, abre la dirección seguida de conectar/ La primera vez dirá que la conexión no es privada: «Configuración avanzada» → continuar.
  2. counter_2
    Instala el certificado La página explica los pasos para Windows o Mac y muestra el código para compararlo.
